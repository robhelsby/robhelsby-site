Alright Chief

First-pass prototype · v0.1

A transition app for new dads who want to feel like themselves while becoming the father their family needs.

Everything is clickable. Data lives in your browser only.

Language interface

Conversational copy is generated live by Claude when a key is connected; otherwise the scripted fallback voice is used. Status: scripted fallback

Key is stored in this browser only and sent directly to the Claude API.

Progress & notifications

Welcome messages and push notifications reflect the dad's transition back to balance, drawn from how his ledger changes over time. Status: off

Real builds schedule these server-side (Push API + service worker); here they fire on demand, plus a demo nudge ~6s after enabling.

Character render

The chief is a drawn, fully interactive vector character — he breathes, blinks, and you can poke, spin and pick him up by the scruff. You can switch to the static reference photo art to compare.

Avatar pipeline (Midjourney)

A bespoke prompt in the house style, built from the dad's answers. Or plug a render straight in. See RENDER_PIPELINE.md for the production path (Rive).
